# 14 狀態與代碼

本文件供 DDL、Java、前端選項與測試對照；Runtime 多處使用字串代碼，異動時仍須逐一核對程式與資料庫。

## 1. 共通

```text
STATUS: ACTIVE, INACTIVE
YES_NO: Y, N
```

`SUSPENDED`、`SUPERSEDED` 與獨立 `COMMENT` Action 屬早期預留代碼，現行 Runtime 未找到對應狀態轉換或動作寫入，不能當作可用操作。

新增代碼必須同步修改本文件、DDL 約束或種子資料、後端驗證與轉態邏輯、前端顯示及測試。
