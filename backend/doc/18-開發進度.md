## 強制開發原則

- FlowMint 前後端程式必須以 `C:\home\qifu4` 現有程式為實作範本。

- Query／Create／Edit 頁面應先選定相近的 QIFU4 範例，再替換為 FlowMint 業務欄位。
- 後端分頁查詢必須使用 QIFU4 的 `setQueryResponseJsonResult(...)` 封裝回應。
- 表單驗證失敗時，前端必須同時套用後端 `checkFields`，並以 `toast.warning(escapeQifuHtmlMsg(response.data.message))` 顯示訊息。

## 2026-07-30 問題修正紀錄

### 必填欄位只有紅框、沒有 toast

原因：前端曾自行加入驗證並提前中止，未依 QIFU4 使用後端回傳訊息。  
修正：Create／Edit 儲存改為接收 `response.data.checkFields`，失敗時呼叫：

```ts
checkFields.value = response.data?.checkFields || {};
toast.warning(escapeQifuHtmlMsg(response.data.message));
```

### SQL 查到資料但 Grid 沒有顯示

後端 log 已確認：

- `fm_tenant` count 為 `1`
- 分頁 SQL 確實查到 Tenant `A01`
- HTTP 回應為 `200 OK`

真正原因：`FMPROG001D0001Controller.findPage()` 手動複製 Service 的 `QueryResult`。Service 內部結果的 `success` 預設為 `N`，造成前端進入失敗分支並保持空 Grid。

已改為 QIFU4 標準結果封裝：

```java
this.setQueryResponseJsonResult(viewResult, result, searchBody.getPageOf());
```

同時前端查詢頁已補上：

- 按「查詢」先回第 1 頁。
- 查詢前清空舊列表。
- QIFU4 成功旗標判斷。
- 空回應、查詢錯誤與分頁總筆數處理。

流程最後一關核准完成、駁回、申請人撤回及實際發起人取消時，會通知表單 Owner 與實際 Starter；兩者相同時自動去重。事件分別保存為 `PROCESS_COMPLETED`、`PROCESS_REJECTED` 或 `PROCESS_CANCELLED`，reference 指向流程實例。

Email 不另建 SMTP client 或寄信排程，而是依 QIFU4 既有機制建立 `TbSysMailHelper`，交由 `SendMailHelperJob` 寄送及重試。收件地址取同 Tenant、啟用且在有效期間內的 `fm_employee.EMAIL`；沒有 Email 時只保留站內通知，不阻斷流程。每封待寄 Email 另寫入 `fm_notification` 的 `EMAIL/PENDING` 紀錄並使用穩定事件 ID 去重，`TbSysMailHelper.RETAIN_FLAG=Y` 以保留 QIFU4 寄送結果。尚待補上 QIFU4 寄送結果回寫 `fm_notification` 的 `SENT/FAILED` 狀態同步，以及可管理的通知範本。

### 2026-08-11 Phase 5：QIFU4 通知範本整合

通知主旨與內容已集中至 `FmNotificationTemplateCatalog`，並對應 QIFU4 `tb_sys_template`／`tb_sys_template_param`：`FMTASKASG`、`FMPROCMP`、`FMPROREJ`、`FMPROCAN`。部署用 `FM_NOTIFICATION-templates.sql` 採 `INSERT IGNORE`，重複執行不覆蓋管理員已調整的範本。

Runtime 優先使用 QIFU4 `TemplateUtils` 與 FreeMarker 參數產生站內通知及 Email 的相同內容；範本尚未部署、資料不完整或渲染失敗時會記錄 warning 並使用內建安全文字，不使簽核交易失敗。範本目錄與 fallback 已有單元測試；本階段未直接異動資料庫。

### 2026-08-11 Phase 5：Email 寄送結果同步

新增 migration `V20260811_01__fm_notification_provider_message_id.sql`，以 `PROVIDER_MESSAGE_ID` 精確保存 QIFU4 `TbSysMailHelper.MAIL_ID`，避免以收件人、主旨或內容猜測寄送關聯。Migration 尚未直接套用資料庫，部署本版程式前必須先執行。
