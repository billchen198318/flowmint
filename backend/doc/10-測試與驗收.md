# 10 測試與驗收

## 1. 測試層級

| 層級 | 範圍 |
|---|---|
| Unit | 樹、層級、狀態機、Resolver、表單驗證 |
| Mapper | Tenant 條件、分頁、索引使用、optimistic update |
| Integration | MariaDB constraint、Transaction、Flowable |
| API | Identity、Permission、Validation、HTTP status |
| Frontend | Form、Tree、Designer、Task action |
| E2E | 建組織到完成簽核 |

## 2. 必測安全案例

- Request body 冒用 initiator／actor。
- 讀取或更新其他 Tenant ID。
- 沒有權限直接呼叫 API。
- 重複 Submit／Approve。
- 已完成 Task 再操作。
- JSON expression injection。
- 附件類型、大小與路徑攻擊。

## 3. 組織案例

- 根部門建立。
- 同 Tenant 唯一部門代碼。
- 父子循環。
- 父層級低於子層級。
- 允許跳級。
- 子樹拖拉、排序、整批回滾。
- stale version。
- 同時兩位 HEAD 重疊。
- Tenant 職稱對應不存在、停用或其他 Tenant 的 Level。
- 員工任職引用不存在、停用或其他 Tenant 的職稱。
- 同一部門職務多人擔任時的模式與優先順序。
- 金額／天數核決條件邊界與重疊。
- Employee 同時兩個主要部門。
- ORG_HEAD 自動帶入直屬主管。
- 部門 HEAD 使用 PARENT_HEAD。
- EXPLICIT 指定主管必須是有效任職。
- 主管不得是自己，也不得形成兩人或多層循環。
- 主管任職失效後新解析建立 Incident，歷史 Snapshot 不變。
- 組織異動不改變舊快照。
- 組織健檢正確列出缺少有效正式主管的非虛擬部門。
- 組織健檢正確列出無法依任職設定解析直屬主管的員工，且不誤報合法最高負責人。
- 組織健檢只允許 Tenant 唯一最高部門無父節點，其他無有效父節點部門均警告。
- A 代理 B、B 代理 A 的有效期間與範圍有交集時只產生一筆警告；期間或範圍無交集時不誤報。
- 健檢重跑與通知具冪等性；修正資料後問題轉為 `RESOLVED`，且不能跨 Tenant 查閱。
- `FM_PROG002D0007Q` 只有一個頁面並固定顯示四個檢查區塊；有問題直接列出，無問題顯示「檢查正常」。
- 部門主管區可檢出同期間多位 `HEAD`、主管任職失效、membership 失效及跨 Tenant 引用。
- 直屬主管區可檢出自我主管、重複主要任職，以及二人與多層主管鏈循環。
- 組織樹區可檢出多根、自我父節點、多層循環、無效父節點及組織版本期間重疊。
- 工作代理區可檢出自我代理、相同時段／範圍多代理人、多層循環、無效人員／範圍／期間及禁止再代理違規。
- 組織人員資料檢查依問題影響正確區分 `ERROR` 與 `WARNING`，並優先顯示 `ERROR`。
- 每筆問題顯示中文說明、可能影響、判定依據、具體調整建議及正確維護入口，且不提供自動改寫正式資料的一鍵修正。

## 4. Resolver 案例

- 本部門主管。
- 父部門主管。
- 下一個較高層級。
- 目標層級。
- 逐級簽到指定層級。
- 根部門主管。
- Acting、Deputy、Workflow Delegation。
- 自簽四種政策。
- 重複三種政策。
- 找不到人建立 Incident。
- Preview 與 Runtime 完全一致。

## 5. 台灣／中國大陸案例

- `zh-TW` 顯示處、部、課、組。
- `zh-CN` 顯示事业部、部门、科室、组。
- 同一 Resolver Code 在兩種名稱下結果一致。
- Tenant timezone 的顯示與有效日判斷正確。
- UTF-8 可保存繁體、簡體及罕見姓名字元。

## 6. 第一個端到端驗收

```text
00001 總公司（HEAD=總經理）
  ├─ 10000 製造處（HEAD=製造處長）
  │   ├─ 11000 生產部（HEAD=生產經理）
  │   │   └─ 11100 生產課（HEAD=課長）
  │   └─ 12000 品保部（HEAD=品保經理）
  └─ 20000 管理處
      ├─ 21000 人力資源部
      └─ 22000 財務部
```

生產課員工發起請假或費用申請，系統依流程規則找到課長、經理、處長或總經理，保存每次表單與指派快照，最後完成或駁回。
