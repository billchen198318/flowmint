```text
P0 Tenant → Employee → Approval Level → Department Tree → Head
P1 Form → Process Designer（內嵌 Task Policy、Resolver Preview 與發布檢查）
P2 Request → Inbox → Approve/Reject/Return → Snapshot
P3 Transfer/Delegate/Add Sign → Incident → Operations
P4 Notification → Reports → optional enhancements
```
